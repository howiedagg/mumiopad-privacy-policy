本政策適用於 Mumio Server Windows 桌面程式，包含 Microsoft Store 版與官方直接下載版。Mumio Server 接收使用者主動從配對手機傳來的指令，提供電腦滑鼠與鍵盤控制。Android 行動應用程式另適用於 Mumio Android 隱私權政策。

1. 資料處理原則

Mumio Server 不要求建立使用者帳號，程式不內建廣告、分析或遙測服務。滑鼠與鍵盤控制資料透過您配置的網路連線在所選手機與電腦之間傳輸，通常為區域網路，也可能經 VPN 或其他可達網路；不會自動傳送給開發者，也不會被出售或用於廣告。輸入文字、剪貼簿文字及裝置名稱可能包含個人資訊，因此本政策說明程式如何存取與處理這些資料。

2. 存取與處理的資料及用途

  • 網路連線與區域探索：程式處理電腦與連線手機的 IP 位址，以建立連線及防止配對濫用。程式使用 mDNS 公告電腦名稱、區域 IP、伺服器識別碼、服務埠與支援的協定版本；同一區域網路中的裝置可接收這些探索資訊。
  • 配對與設定：程式在電腦本機保存伺服器 UUID、TLS 金鑰及憑證、已配對手機名稱、配對裝置識別碼、配對 token 的 SHA-256 雜湊、最後連線時間及使用者設定，例如介面語言。這些資料用於辨識已授權裝置、保護連線及保留設定。
  • 滑鼠與鍵盤輸入：程式接收並執行手機送來的移動、點擊、捲動、手勢、按鍵及文字指令，將輸入送至您正在控制的 Windows 應用程式。程式不建立或保存控制內容與輸入文字的歷史紀錄。
  • 剪貼簿文字：為完成文字貼上，程式會讀取當時可讀取的 Windows 剪貼簿文字，暫時將手機傳來的文字放入剪貼簿並執行貼上，然後嘗試還原先前的文字；沒有可還原文字時則清除暫放的內容。原有剪貼簿文字不會傳回手機或自動傳給開發者，也不會保存為剪貼簿歷史。
  • 執行與錯誤資訊：程式在執行期間處理連線狀態與錯誤訊息，可能包括裝置名稱、IP 位址或錯誤細節，用於呈現狀態及處理連線問題。程式不會自動將這些訊息上傳給開發者。

文字可能包含您主動輸入的姓名、電話或其他個人資訊。貼上後，目標 Windows 應用程式以及 Windows 剪貼簿歷程或同步功能（若您啟用）如何保存或傳輸文字，取決於其功能、設定與隱私權政策。

3. 使用、傳輸與揭露

上述資料用於提供您主動要求的配對、裝置連線、滑鼠與鍵盤控制、設定保存及問題處理。您可以拒絕配對請求、停止傳送輸入、解除配對，或退出 Mumio Server 以停止連線服務。

控制內容只交給您選擇的電腦及目標應用程式；mDNS 探索資訊則會公告至所在區域網路。Mumio Server 不會自動將控制內容、剪貼簿內容、配對憑證或裝置清單提供給開發者、廣告商或分析服務。更新、政策網頁及您主動提出的支援請求涉及的第三方服務見第 6、7 節。

4. 儲存與安全

配對與設定資料保存在目前 Windows 使用者的本機資料範圍。直接下載版使用 %APPDATA%\Mumiopad；Microsoft Store 版使用 Windows 管理的應用程式資料位置，Windows 可能將相同的邏輯路徑重新導向至套件專屬資料夾。資料不會為 Mumio 帳號建立雲端備份。

Wi-Fi 控制連線使用 WSS/TLS，加上電腦公鑰驗證、使用者確認配對及配對 token 驗證。電腦端只保存 token 的 SHA-256 雜湊，不保存原始 token。TLS 私鑰與設定檔由 Windows 使用者帳戶及檔案存取控制管理，程式不另外對這些本機檔案提供應用程式層的加密。

5. 資料保留、存取與使用者控制

  • 查看與撤銷配對：您可在主畫面或系統匣的裝置清單查看配對裝置，並解除單一配對或清除所有配對。解除配對會刪除該電腦保存的裝置配對紀錄並撤銷該裝置的存取權限；不會刪除其他程式已收到的文字或手機端獨立保存的資料。
  • 保留期間：配對紀錄保留至您解除或清除配對；伺服器身分與設定保留至您刪除相應本機資料。控制指令與剪貼簿暫存文字只用於執行當次操作，程式不持久保存這些內容。
  • 刪除本機資料：直接下載版解除安裝後，設定可能仍保留；完整刪除前請先退出程式，再刪除 %APPDATA%\Mumiopad。Store 版解除安裝時，由 Windows 清除套件管理的資料；若曾使用直接下載版，該版本留下的資料仍需另外處理。請只刪除您要移除之版本的資料。
  • 其他隱私請求：您可透過第 7 節的公開聯絡入口提出適用法律下的資料存取、更正、刪除或其他隱私請求。開發者無法遠端存取您電腦上的本機配對資料、剪貼簿或輸入內容；這些資料由您在自己的裝置上控制。

6. 更新與第三方服務

  • Microsoft Store 版：安裝與更新由 Microsoft Store 管理，程式不使用直接下載版的 GitHub 更新器。Microsoft 可能依其服務設定與政策處理下載、裝置或診斷資料；詳見 Microsoft 隱私權聲明。
  • 直接下載版：程式會連線至 GitHub Releases 檢查及下載更新，並在本機記錄更新檢查時間。GitHub 會處理提供服務所需的網路資料，例如 IP 位址與請求資訊。更新請求不包含您輸入的文字、剪貼簿內容或配對憑證。
  • Store 報表：Microsoft 可能向開發者提供商店統計或錯誤報告。若開發者收到這些資料，僅用於改善程式及排除問題，不用於辨識個別使用者或廣告。若 Microsoft 提供的錯誤報告含個人資訊，開發者依 Microsoft 開發者協議在安全且限制存取的環境處理，並於收到後 30 天內刪除該個人資訊，或依 Microsoft 要求提前刪除。
  • 政策網頁與聯絡入口：本頁由 GitHub Pages 提供，聯絡入口使用 GitHub Issues。GitHub 依 GitHub 隱私權聲明處理連線及您提供的資料。

7. 聯絡開發者與政策更新

開發者：Mumio（GitHub：howiedagg）。政策或資料處理問題可透過 Mumio 隱私權政策 GitHub Issues提出。此入口為公開討論；您提交的內容可能公開顯示，請只提供處理問題所需的資訊，不要張貼輸入文字、剪貼簿內容、配對 token 或 TLS 私鑰。開發者僅將您主動提供的支援資料用於回覆與處理請求，自行持有的副本保留至請求處理完成且不再需要後續追蹤，之後刪除；您也可提出刪除請求。GitHub 上公開議題的保留與刪除另受其平台功能及政策影響。

本政策會隨實際資料處理方式調整，並更新本頁的最後更新日期。

English

This policy applies to Mumio Server for Windows, including the Microsoft Store edition and the official direct-download edition. Mumio Server receives commands that you intentionally send from a paired phone to control your PC's mouse and keyboard. The Android mobile app is covered by the Mumio Android privacy policy.

1. Data Processing Principles

Mumio Server does not require a user account and has no built-in advertising, analytics, or telemetry services. Mouse and keyboard control data travels between your chosen phone and PC over the network connection you configure, usually a local network but potentially a VPN or another reachable network. It is not automatically sent to the developer, sold, or used for advertising. Input text, clipboard text, and device names may contain personal information, so this policy explains how the application accesses and processes them.

2. Data Accessed and Processed, and Its Purpose

  • Network connections and local discovery: The application processes the PC's and connecting phone's IP addresses to establish connections and prevent pairing abuse. Through mDNS, it advertises the PC name, local IP addresses, server identifier, service port, and supported protocol versions. Devices on the same local network can receive this discovery information.
  • Pairing and preferences: The application stores the server UUID, TLS key and certificate, paired phone names, pairing device identifiers, SHA-256 hashes of pairing tokens, last-connection times, and preferences such as interface language locally on the PC. These data identify authorized devices, protect connections, and preserve preferences.
  • Mouse and keyboard input: The application receives and executes movement, click, scroll, gesture, key, and text commands from the phone, sending input to the Windows application you are controlling. It does not create or retain a history of control content or input text.
  • Clipboard text: To paste text, the application reads the Windows clipboard text that is accessible at that moment, temporarily places text received from the phone on the clipboard, and pastes it. It then attempts to restore the previous text, or clears the temporary content when no text can be restored. Existing clipboard text is not sent back to the phone or automatically sent to the developer, and the application does not save a clipboard history.
  • Runtime and error information: During execution, the application processes connection status and error messages, which may include device names, IP addresses, or error details, to display status and handle connection problems. It does not automatically upload these messages to the developer.

Text may include names, telephone numbers, or other personal information that you intentionally enter. After pasting, how the destination Windows application or Windows clipboard history or synchronization features (if you enable them) retain or transmit text depends on their features, settings, and privacy policies.

3. Use, Transmission, and Disclosure

The data described above is used to provide the pairing, device connection, mouse and keyboard control, preference storage, and troubleshooting functions that you actively request. You can reject pairing requests, stop sending input, revoke pairings, or quit Mumio Server to stop the connection service.

Control content is delivered only to your chosen PC and destination application; mDNS discovery information is advertised to the local network. Mumio Server does not automatically disclose control content, clipboard content, pairing credentials, or device lists to the developer, advertisers, or analytics services. Third-party services involved in updates, this policy page, and support requests you initiate are described in Sections 6 and 7.

4. Storage and Security

Pairing data and preferences are stored in the current Windows user's local data area. The direct-download edition uses %APPDATA%\Mumiopad. The Microsoft Store edition uses Windows-managed application storage; Windows may redirect the same logical path to a package-specific folder. These data are not backed up to a Mumio cloud account.

Wi-Fi control connections use WSS/TLS, PC public-key verification, user-confirmed pairing, and pairing-token authentication. The PC stores SHA-256 token hashes rather than raw tokens. TLS private keys and configuration files are managed through the Windows user account and file access controls; the application does not provide additional application-level encryption for these local files.

5. Retention, Access, and User Controls

  • Viewing and revoking pairings: You can view paired devices in the main window or system-tray device list and remove one pairing or clear all pairings. Removing a pairing deletes that device's pairing record on the PC and revokes its access. It does not remove text already received by other applications or data independently stored on the phone.
  • Retention: Pairing records remain until you remove or clear them. Server identity and preferences remain until you delete the corresponding local data. Control commands and temporary clipboard text are used only to execute the current operation; the application does not persist them.
  • Deleting local data: The direct-download edition may leave preferences after uninstalling. To remove them completely, first quit the application and then delete %APPDATA%\Mumiopad. When the Store edition is uninstalled, Windows removes package-managed data. Data left by a previously used direct-download edition must be handled separately. Delete only the data for the edition you intend to remove.
  • Other privacy requests: You can use the public contact channel in Section 7 to request access, correction, deletion, or other privacy rights available under applicable law. The developer cannot remotely access local pairing data, clipboard content, or input text on your PC; you control those data on your own devices.

6. Updates and Third-Party Services

  • Microsoft Store edition: Installation and updates are managed by Microsoft Store. The application does not use the direct-download edition's GitHub updater. Microsoft may process download, device, or diagnostic data according to its service settings and policies; see the Microsoft Privacy Statement.
  • Direct-download edition: The application connects to GitHub Releases to check for and download updates and records update-check times locally. GitHub processes network data needed to provide the service, such as IP addresses and request information. Update requests do not include input text, clipboard content, or pairing credentials.
  • Store reports: Microsoft may provide store statistics or error reports to the developer. If received, these data are used only to improve the application and resolve problems, not to identify individual users or for advertising. If error reports provided by Microsoft contain personal information, the developer handles it in a secure environment with restricted access and deletes that personal information within 30 days of receipt, or earlier if Microsoft requests, as required by the Microsoft App Developer Agreement.
  • Policy page and contact channel: This page is hosted on GitHub Pages, and the contact channel uses GitHub Issues. GitHub processes connection data and information you provide under the GitHub Privacy Statement.

7. Developer Contact and Policy Changes

Developer: Mumio (GitHub: howiedagg). For policy or data-processing questions, use Mumio privacy-policy GitHub Issues. This is a public discussion channel; submitted content may be publicly visible. Provide only information needed to address your question, and do not post input text, clipboard content, pairing tokens, or TLS private keys. The developer uses support information you actively provide only to respond to and handle your request. Copies held independently by the developer are retained until the request is resolved and follow-up is no longer needed, then deleted; you can also request their deletion. Retention and deletion of public issues on GitHub separately depend on the platform's features and policies.

This policy will be updated when actual data-processing practices change, with the last-updated date shown on this page.
