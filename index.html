Mumio Privacy Policy / Mumio 隱私權政策

Last Updated / 最後更新日期: 2026-08-29

繁體中文

Mumio（原名 Mumiopad）包含 Android 行動應用程式與 Windows 電腦端程式 Mumio Server。本政策說明產品為提供無線觸控板與鍵盤功能而處理的資料、權限及使用者控制。

1. 核心隱私原則

Mumio 不提供使用者帳號，不使用廣告、分析或遙測服務，也不會將控制內容出售或提供給開發者。核心控制資料只會在使用者自己的手機與所選裝置之間，透過區域網路或藍牙傳輸。

2. 處理的資料與用途

  • 區域網路探索：Mumio Server 透過 mDNS 在區域網路中公告電腦名稱、區域 IP、服務識別碼與支援的協定版本，讓手機找到可連線的電腦。配對時，手機會將製造商與型號組成的裝置名稱傳給所選電腦。Mumio Server 會在連線期間處理來源區域 IP，並可能將它記入本機錯誤紀錄。
  • 控制與鍵盤輸入：滑鼠移動、點擊、捲動、手勢、按鍵及使用者主動輸入的文字會直接傳送到被控制的裝置。Mumio 與 Mumio Server 不會將這些控制內容保存到資料庫或傳給開發者。Wi-Fi 文字輸入會在 Windows 剪貼簿中短暫放入文字以完成貼上，之後清除或還原原本可讀取的文字內容。
  • Wi-Fi 網路識別：Android App 會在本機讀取並保存目前 Wi-Fi 路由器的 BSSID，用來記住該網路預設連線的電腦。BSSID 不會傳送給開發者，也不會用來取得或追蹤 GPS 座標。
  • 配對與裝置資料：Android App 會在本機保存電腦名稱、UUID、最後已知區域 IP、配對 token、TLS 公鑰 pin、藍牙裝置位址及使用者設定。Mumio Server 會在本機保存伺服器 UUID、TLS 身分檔、已配對手機名稱、token 的 SHA-256 雜湊、最後連線時間與語言設定。

3. Android 權限

  • 位置權限（ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION）：Android 將 BSSID 視為可能與位置相關的 Wi-Fi 資訊，因此讀取 BSSID 需要位置權限。Mumio 不會讀取、保存或傳輸 GPS／實際地理座標。
  • 藍牙權限（BLUETOOTH_CONNECT）：用於連線系統已配對的藍牙裝置，並提供藍牙 HID 滑鼠與鍵盤功能。
  • 網路與鄰近 Wi-Fi 權限（INTERNET / NEARBY_WIFI_DEVICES）：用於區域網路 WSS/TLS 通訊、mDNS 探索及連線狀態判斷。

4. 儲存與安全

Android 的 Wi-Fi 配對憑證使用 EncryptedSharedPreferences 加密保存；BSSID 對應、藍牙裝置位址與一般設定則保存在 Android App 的私有儲存空間，且 App 已停用 Android 備份。Wi-Fi 控制連線使用 WSS/TLS、PC 公鑰 pin、使用者確認碼及配對 token。Mumio Server 只保存 token 的 SHA-256 雜湊，不保存原始 token。

Mumio Server 的設定、TLS 身分與本機錯誤紀錄位於目前 Windows 使用者的 %APPDATA%\Mumiopad 資料夾。該舊名稱為相容性識別，不代表目前產品名稱。

5. 更新與第三方服務

Microsoft Store 版由 Microsoft Store 管理更新，不使用 Mumio Server 的外部更新程式。從官方網站直接安裝的 EXE 版會連線至 GitHub Releases 檢查及下載更新；GitHub 可能依其政策處理一般網路資料，例如 IP 位址與請求資訊。本隱私政策頁面亦由 GitHub Pages 提供，因此 GitHub 會處理提供網頁所需的連線資料。Mumio 不使用第三方廣告或分析服務。

6. 資料保留與刪除

  • 使用者可在 Android App 或 Mumio Server 托盤選單解除單一配對；Mumio Server 也能清除全部已配對裝置。
  • 移除 Android App 或清除其 App 資料會刪除 Android 端保存的本機資料。
  • 解除安裝 Mumio Server 後，Windows 本機設定可能仍保留。若要完整刪除，請先結束 Mumio Server，再刪除 %APPDATA%\Mumiopad。

7. 聯絡我們

若對本政策或資料處理有疑問，請透過 Mumio GitHub Issues 聯絡開發者。

English

Mumio (formerly Mumiopad) includes the Android mobile app and the Windows companion application, Mumio Server. This policy explains the data and permissions processed to provide wireless touchpad and keyboard functionality.

1. Core Privacy Principles

Mumio has no user accounts and uses no advertising, analytics, or telemetry services. It does not sell control data or provide it to the developer. Core control data travels only between the user's own phone and selected device over the local network or Bluetooth.

2. Data Processed and Its Purpose

  • Local network discovery: Mumio Server advertises the PC name, local IP address, service identifier, and supported protocol version through mDNS so the phone can find it. During pairing, the phone sends a device name composed from its manufacturer and model to the selected PC. Mumio Server processes the peer's local IP during a connection and may include it in a local error log.
  • Control and keyboard input: Pointer movement, clicks, scrolling, gestures, key commands, and text intentionally entered by the user are sent directly to the controlled device. Mumio and Mumio Server do not retain this control content in a database or send it to the developer. For Wi-Fi text input, Mumio Server temporarily places the text on the Windows clipboard to paste it, then clears it or restores the previous readable text value.
  • Wi-Fi network identification: The Android app reads and stores the current router BSSID locally to remember which PC is preferred on that network. The BSSID is not sent to the developer and is not used to obtain or track GPS coordinates.
  • Pairing and device data: The Android app stores the PC name, UUID, last known local IP, pairing token, TLS public-key pin, Bluetooth device addresses, and preferences locally. Mumio Server stores its server UUID, TLS identity files, paired phone names, SHA-256 token hashes, last-connection times, and language preference locally.

3. Android Permissions

  • Location permissions (ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION): Android treats BSSID as Wi-Fi information that may be associated with location, so these permissions are required to read it. Mumio does not read, retain, or transmit GPS or physical location coordinates.
  • Bluetooth permission (BLUETOOTH_CONNECT): Used to connect to system-paired Bluetooth devices and provide Bluetooth HID mouse and keyboard functionality.
  • Network and nearby Wi-Fi permissions (INTERNET / NEARBY_WIFI_DEVICES): Used for local WSS/TLS communication, mDNS discovery, and connectivity checks.

4. Storage and Security

Android Wi-Fi pairing credentials are encrypted with EncryptedSharedPreferences. BSSID mappings, Bluetooth device addresses, and general preferences are stored in the app's private Android storage, and Android backup is disabled. Wi-Fi control connections use WSS/TLS, PC public-key pinning, a user-confirmed verification code, and pairing tokens. Mumio Server stores only SHA-256 hashes of tokens, not raw tokens.

Mumio Server settings, TLS identity, and local error log are stored for the current Windows user under %APPDATA%\Mumiopad. The legacy folder name is retained as a compatibility identifier and is not the current product name.

5. Updates and Third-Party Services

The Microsoft Store edition is updated by Microsoft Store and does not use Mumio Server's external updater. The direct EXE edition from the official website connects to GitHub Releases to check for and download updates. GitHub may process ordinary network data such as IP addresses and request information under its own policies. This privacy-policy page is also served by GitHub Pages, so GitHub processes the connection data needed to deliver it. Mumio uses no third-party advertising or analytics services.

6. Retention and Deletion

  • Users can remove an individual pairing from the Android app or Mumio Server tray menu. Mumio Server can also clear all paired devices.
  • Uninstalling the Android app or clearing its app data removes locally stored Android data.
  • Local Windows settings may remain after Mumio Server is uninstalled. To remove them completely, exit Mumio Server and delete %APPDATA%\Mumiopad.

7. Contact Us

For questions about this policy or data processing, contact the developer through Mumio GitHub Issues.
